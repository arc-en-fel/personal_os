# ⚡ Notifications - Quick Start (30 Seconds)

## How to Add a Notification (Like Google Calendar)

### 3 Simple Steps

```
STEP 1: Open Event
┌─────────────────────────┐
│ Calendar                │
│ ┌─ Meeting (today)      │
│ ├─ Lunch (tomorrow)     │
│ └─ Flight (next week)   │
│                         │
│ Tap any event ✓         │
└─────────────────────────┘

STEP 2: Scroll Down to "Notifications"
┌─────────────────────────┐
│ EVENT TITLE             │
│ Today 10:00 AM          │
│                         │
│ NOTIFICATIONS ─ + Add   │ ← TAP THIS
│ (empty)                 │
│                         │
│ [Edit] [Delete]         │
└─────────────────────────┘

STEP 3: Tap "+ Add notification"
┌─────────────────────────────────┐
│ ✕    Add notification           │
│                                 │
│ When to notify                  │
│  At time of event               │
│  5 minutes before               │
│  10 minutes before              │
│  15 minutes before      ✓       │
│  30 minutes before              │
│  1 hour before                  │
│  1 day before                   │
│                                 │
│ How to notify                   │
│  🔔 Notification        ✓       │
│  📧 Email                       │
│                                 │
│ [Cancel] [Add]                  │
└─────────────────────────────────┘

✓ Select timing (default: 15 min)
✓ Select type (default: Notification)
✓ Tap "Add"

✅ DONE!
```

---

## What Each Option Does

### When to Notify
- **At time of event** → Exactly when event starts
- **5 minutes before** → 5 min before event starts
- **10 minutes before** → 10 min before event starts
- **15 minutes before** → 15 min before event starts (default)
- **30 minutes before** → 30 min before event starts
- **1 hour before** → 1 hour before event starts
- **1 day before** → 1 day before event starts

### How to Notify
- **🔔 Notification** → Push notification on phone
- **📧 Email** → Email to your account

## Example: Doctor Appointment Tomorrow at 2 PM

### What You Do
```
1. Calendar → Find "Doctor Appointment"
2. Tap event
3. Scroll to NOTIFICATIONS
4. Tap "+ Add notification"
5. Select "1 day before"
6. Select "📧 Email"
7. Tap "Add"

Repeat:
8. Tap "+ Add notification"
9. Select "15 minutes before"
10. Select "🔔 Notification"
11. Tap "Add"
```

### What You Get
```
NOTIFICATIONS
🔔 15 minutes before
📧 1 day before
```

### When You're Notified
```
TOMORROW
7:00 PM (today)
  └─ Email arrives!

TOMORROW (event day)
1:45 PM
  └─ Push notification pops up!
     "Doctor Appointment in 15 min"

2:00 PM
  └─ Event starts!
```

## Tips

### Tip 1: Multiple Notifications
Add different notification types:
- 1 day before (email)
- 1 hour before (push)
- 15 min before (push)

### Tip 2: Important Events
For critical events:
- 1 day before (email reminder)
- 30 min before (push notification)

### Tip 3: Flexible Timing
Choose timing that works for you:
- Meetings: 15 minutes before
- Flights: 1 day before + 2 hours before
- Reminders: At time or 5 min before
